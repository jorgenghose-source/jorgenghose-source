# AURORA-8 — Stage 1
Run `python3 -m http.server 8000` in this directory and open http://localhost:8000 in Chrome. Click Start audio, then play the keys. No network dependencies. Direct file:// launch of modular build is not supported.

Core: two PolyBLEP oscillators per voice, leaky integrated triangle, approximate colored noise, first-order HPF, cascaded TPT lowpass, exponential envelopes, stereo voice summing. The 24 dB mode cascades a resonant stage and fixed-Q stage; not a component-level Jupiter model. Parameter definitions and defaults are in state.js. Voice stealing uses a 64-sample fade. UI uses accessible sliders and numeric fields rather than final rotary knobs.

Test: `node tests/core.cjs`. This runs the actual processor in a simulated worklet environment, not a browser audio device. Browser playback, aliasing, tuning, stress, latency and accessibility have not been verified. No claim of production readiness. Stage 2–6 features are absent, including sync, cross modulation, MIDI, presets, LFOs, sequencing, effects and export. Noise coloration is approximate; phase is retained during inactive voices rather than continuously advanced. Timing of UI note messages is render-block based. Smoothing currently uses a fixed per-sample coefficient. Latency setting applies before initialization. Chrome/Edge/Firefox/Safari compatibility is unverified; requires AudioWorklet and secure context (localhost qualifies).
