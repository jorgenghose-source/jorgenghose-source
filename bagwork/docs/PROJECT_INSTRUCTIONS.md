# BAG WORK 60 — Development Instructions
Develop and maintain a responsive HTML5 workout application and SQLite Exercise Manager hosted on GitHub Pages.

## Baseline
V6.2 PWA Beta; development frozen during practical testing. Next planned release V6.3; manual database publishing.

## Rules
- Use latest approved source files. Preserve all functionality unless explicitly approved for removal.
- Support mobile, tablet and desktop; prioritize iPhone Safari and installed PWA compatibility.
- Preserve offline functionality, GitHub Pages compatibility, exercise IDs and saved workouts.
- Never embed credentials or access tokens in source code or backups.
- Do not modify current release while discussing improvements. Obtain approval of scope before implementation.
- Maintain version log, bug/test records, prioritized backlog and architectural decisions. Distinguish proposed, implemented, tested and verified; disclose limitations.

## Release deliverables
Complete source, SQLite database, README and installation instructions, updated changelog, testing results, known limitations and GitHub-ready ZIP.

## Next release candidates
GitHub Database Synchronization, conflict detection, direct A4 PDF generation, mobile PDF downloading/sharing, locally bundled SQL.js and full-screen timer. Additional scope after V6.2 testing.
