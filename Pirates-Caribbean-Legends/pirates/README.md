# Pirates: Caribbean Legends — milestone build 0.1
Open index.html after extracting the archive, or open the standalone HTML file. No network or server is required. Local file storage behavior varies by browser; export JSON backups. Desktop: WASD/arrows, Space interact, M chart, J journal, F fleet, I cargo, Escape pause. Tap water for destination steering. Touch buttons steer and interact. Battle: Q/E broadsides, 1–3 ammunition, B boarding. In the duel match the announced attack with a parry. Visit a governor to accept and deliver dispatches; taverns sell charts, which can be searched near the named port via journal. Retirement and division are available in friendly ports.
## Architecture
Data definitions and pure helpers in js/data.js; browser runtime in js/game.js with centralized serializable state, fixed-step update and separate canvas rendering. CSS in css/main.css. Original geometric procedural graphics and oscillator effects; no third-party assets. Run `node --test tests/core.test.js` and `node --check js/game.js`.
## Milestone checklist and limitations
Implemented in simplified form: captain creation, 46 ports, 14 ship classes, sailing, local obstacle avoidance, traffic, market, food and morale, reputation, naval combat, timed menu duels, capture, flagship selection, dispatch quests, chart rewards, repairs, three upgrades, plunder, retirement, local saves and JSON transfer. Offline files are self-contained; no service worker. No browser integration tests executed. Geography and era ownership are approximate, navigation can get stuck, AI traffic does not avoid land, battle state is not persisted, save validation is shallow. Food uses a separate hold. No full historical diplomacy, rival pirates, overland exploration, land combat, stealth, romance, aging, music, advanced accessibility, full tutorial, or full fleet management. Artwork is basic rather than production pixel art. Next: route finding and browser integration tests, robust transactions and save validation, then richer simulation and adventure systems. This is not the final definition-of-done release.
